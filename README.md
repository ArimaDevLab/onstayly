# いるだけの町 (onstayly)

話さなくていい。歩いているだけで、ほかの人の気配がわかる小さな町。
オンラインでのやり取りは苦手だけれど、孤独感は消したい人のためのウェブアプリです。

- 人型のキャラクターで歩くだけ。チャットはありません。
- 「手を振る」「会釈」だけはできます。相手は選べず、自分がその場で動くだけです(通知も回数もなし)。
- 頭の上に「勉強中」「ゲーム中」など、いましていることが出ます(選ぶだけ、自由入力なし)。
- 図書館のテラスや露天風呂など、場所に入るだけで表示が変わります。
- 決まった時刻に町の鐘が鳴り、同じ時間にごはん・運動・おふろ・消灯をします。21:30 には小中学生向けのおやすみの鐘が鳴ります。
- 足あとは1分、いた場所は3時間(おやすみ中は8時間)、薄れながら残ります。
- 「いま○人」「今日は○人が立ち寄りました」が出ます。

## 町のイベント

時計から決まるので、全員が同じ瞬間に同じものを見ます(時刻は日本時間)。

| イベント | いつ | 試すときのアドレス末尾 |
|---|---|---|
| 屋台でもらう | 屋台は交差点の手前で2分止まる。近くに立つと焼き芋(かき氷)をもらえる | `#imo` |
| 雨(傘をさす) | 1時間ごとに決まり、だいたい8時間に1回 | `#rain` |
| 雪 | 12月〜2月の雨のかわり | `#snow` |
| 流れ星 | 夜、数分に1回 | `#star` |
| 花火 | 土日の20:00〜20:10、公園の池の上 | `#hanabi` |
| 焼き芋屋(4〜9月はかき氷屋) | 10時〜21時の毎時40分に大通りへ来る | `#imo` |
| 桜 | 3/25〜4/10 | `#sakura` |
| 紅葉 | 10/15〜11/30 | `#momiji` |

## 図書館の中

図書館の建物(または入口)をタップすると中に入れます。中は町とは別の部屋で、同じ部屋にいる人だけが見えます。

- 机が9台(18席)。席の近くで止まると自動で座り、「勉強中 42分」のように席に着いてからの時間が出ます(記録はしません)。
- 読書コーナーのいすに座ると「読書中」。
- 席に着いている間は画面が自動で消えません(対応ブラウザのみ)。
- ほかのアプリやタブに切りかえて15秒たつと、ほかの人には「席をはずしています」と見え、勉強時間が止まります。
- 壁にみんなで共通のポモドーロ(毎時 0〜25分・30〜55分が集中、残りが休憩)。
- 町の入口には「中に○人」と出ます。中にいる間の痕跡は、入口の前に残ります。

## みんなの塔

ゲームセンターの左に、町のみんなで建てる塔があります。図書館の席で1分勉強するとレンガが1個増え(5分ごとにまとめて送信)、塔が伸びます。
5段(100・300・600・1,000・1,500個)で1本が完成し、段が完成するたびに塔の上に花火が上がります。完成した塔は旗として残り、次の塔を建て始めます。
塔のふもとでは、休憩の5分だけ「つみき」で遊べます。積めた数(最大20個)がレンガに足されます。
試すときは `#tower`(勉強時間が60倍速で進む)、`#party`(完成の花火)。

## ボウリング

ゲームコーナーで、ポモドーロの休憩の5分(毎時25〜30分・55〜60分)だけ遊べます。1ゲームは3フレームで、1分ほどで終わります。
たおしたピンは「今日、町のみんなでたおした合計」に足され、ゲームコーナーの看板に出ます。個人の記録や順位はありません。
試すときは `#game`(いつでも遊べる)。データベースに `town_counters` が必要なので、`supabase/schema.sql` を実行してください。

## 町の住人

司書さん(図書館の中)、番台さん、食堂の人、そうじの人がいます。本物の人ではないので、エプロンや帽子で見分けがつくようにし、役割名だけを表示して、人数には数えません。昼の間だけ出てきます。

## 動物と焚き火

猫は公園を、犬は大通りを回り、着いた先でしばらく座ります。座っている動物のそばに立つと、隣に座れます。
池には鴨と魚がいます。公園の焚き火のまわりとベンチにも座れます。動物の動きも時計から決まるので、全員に同じ場所に見えます。

## 車

大通りを車がゆっくり走ります(昼は1分に1〜2台、深夜はまれ)。前に人がいると止まって待ちます。試すときは `#car`。

## 環境音

「音」ボタンから、雨・虫の声・お湯・池・焚き火・車を個別に調節できます。初めは無音です。
音は `sound.js` でプログラムから合成しています(音声ファイルなし)。

## しくみ

| ファイル | 役割 |
|---|---|
| `index.html` / `app.js` | 町の表示と動き |
| `sound.js` | 環境音 |
| `bowling.js` | ボウリング |
| `stack.js` | つみき |
| `config.js` | Supabase の接続先と、痕跡を残す時間 |
| `supabase/schema.sql` | データベースの設定(痕跡と今日の人数) |
| `vendor/` | Supabase のライブラリ |

サーバーは Supabase だけです。いまいる人は Realtime、痕跡と人数はデータベースの関数を使います。
保存するのは「場所・していたこと・服の色・時刻」だけで、誰のものかは保存しません。

## 初回の設定

1. Supabase の SQL Editor に `supabase/schema.sql` の中身を貼って Run。
2. GitHub の Settings → Pages で、Branch を `main` / `/ (root)` にして Save。
