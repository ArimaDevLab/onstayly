# いるだけの町 (onstayly)

話さなくていい。歩いているだけで、ほかの人の気配がわかる小さな町。
オンラインでのやり取りは苦手だけれど、孤独感は消したい人のためのウェブアプリです。

- 人型のキャラクターで歩くだけ。チャットはありません。
- 「手を振る」「会釈」だけはできます。相手は選べず、自分がその場で動くだけです(通知も回数もなし)。
- 頭の上に「勉強中」「ゲーム中」など、いましていることが出ます(選ぶだけ、自由入力なし)。
- 図書館のテラスや露天風呂など、場所に入るだけで表示が変わります。
- 決まった時刻に町の鐘が鳴り、同じ時間にごはん・運動・おふろ・消灯をします。
- 足あとは1分、いた場所は3時間(おやすみ中は8時間)、薄れながら残ります。
- 「いま○人」「今日は○人が立ち寄りました」が出ます。

## しくみ

| ファイル | 役割 |
|---|---|
| `index.html` / `app.js` | 町の表示と動き |
| `config.js` | Supabase の接続先と、痕跡を残す時間 |
| `supabase/schema.sql` | データベースの設定(痕跡と今日の人数) |
| `vendor/` | Supabase のライブラリ |

サーバーは Supabase だけです。いまいる人は Realtime、痕跡と人数はデータベースの関数を使います。
保存するのは「場所・していたこと・服の色・時刻」だけで、誰のものかは保存しません。

## 初回の設定

1. Supabase の SQL Editor に `supabase/schema.sql` の中身を貼って Run。
2. GitHub の Settings → Pages で、Branch を `main` / `/ (root)` にして Save。
